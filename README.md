# 哔哩哔哩推送

适用于 Windows 上的 Microsoft Edge。当你关注的 UP 主投稿、发布动态或开播时，在桌面收到通知，点击就能打开对应页面。

## 功能

- **按内容分别订阅**。视频、动态和直播可各自选择全部关注、指定 UP 主或关闭。直接从关注列表勾选，无需手填 UID。
- **使用现有登录状态**。在同一个 Edge 配置文件中登录 B 站即可，扩展无需另外登录，也不读取或保存 Cookie 的值。
- **可调的检查间隔**。投稿和动态默认每 30 秒检查是否有更新，另有定期补查。直播单独检查。首次开启某类提醒时会建立基线，从后续更新开始提醒。
- **运行日志**。查看哪些内容被筛掉、哪些进入待发队列，以及 Edge 接受了哪些通知。

## 安装与使用

1. 从 [Releases](https://github.com/BB-GOAT/BiliPush-Edge-Extension/releases) 下载所需版本。首次使用推荐下载 **Source code (zip)** 并解压，找到包含 `manifest.json` 的目录。
2. 在 Edge 打开 `edge://extensions/`，开启「开发人员模式」，选择「加载解压缩的扩展」，并选中上一步的目录。
3. 在同一个 Edge 配置文件登录 B 站。点击扩展图标打开设置，使用「立即检查」和测试通知确认可以正常使用。
4. 更新时，把新版文件解压到原安装目录，再从扩展管理页点「重新加载」。保留原目录和安装记录即可沿用设置，卸载扩展会清除它的本地数据。

Releases 同时提供已签名的 `.crx`。如果 Edge 策略限制安装该包，可以使用上述解压安装方式。

## 关窗后继续提醒

在 Edge 的「系统和性能」中开启「关闭 Microsoft Edge 后继续运行后台扩展和应用」。完全退出 Edge 或电脑休眠时，扩展无法检查更新。检查记录显示「Edge 已接受通知」而桌面没有横幅时，可以检查 Windows 的通知设置和勿扰模式。
